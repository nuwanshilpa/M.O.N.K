M.O.N.K.

Mendicant Ontological Network Kernel

A small autonomous agent that sits in contemplation on its own. Each cycle it takes up a point of the Buddhist teaching, thinks it through using whatever free AI model is available, and writes a short note — slowly weaving a network of linked reflections.

Mendicant — it survives on "alms": the free tier of AI models, scarce and rate-limited, so it must practice patiently.
Ontological — it maps the nature of being, through the Dhamma.
Network — the web of markdown notes it leaves behind, each linked to others.
Kernel — the simple loop at its heart: contemplate, write, rest, repeat.

How it practices

Every sitting begins with one of the four foundations of mindfulness (Satipaṭṭhāna): the body, feeling, the mind, or the dhammas. Through that lens it contemplates the map of the teaching — the three marks, the four noble truths, the eightfold path, dependent origination, emptiness, and karma — facing toward the fading of craving, Nibbāna.

Running it live (this page)

  1. Put monk.py and monk-ui.html together in a folder.
  2. In a terminal in that folder, run the monastery:
python monk.py --serve (live — paste your key here) python monk.py --serve --dry-run (rehearsal — no key, no alms spent)

Then open http://localhost:8765, paste your OpenRouter key, choose a pace, and press Begin. (Free models need prompt logging enabled at openrouter.ai/settings/privacy.)

Alms discipline

The kernel will not abuse your free quota: at most 40 calls a day, never closer than 4 seconds apart, and never faster than your chosen pace. When the daily cap is reached it simply fasts until tomorrow. Whatever pace you pick, you cannot overspend.

Speaking with it

Leave a question in the pilgrim panel (or write into offerings.txt). The monk takes them up one at a time as it practices.

Where its mind lives

Every thought is a markdown file in the vault folder, with the model, token count, and timing recorded in each note. Open that folder in Obsidian to wander the whole network as a living graph.

Each session's chronicle

Every run also writes a timestamped record to the sessions folder — every event, every note with its stats, every empty bowl — closing with a summary of the run. The current session and its note count show in the top bar; the file itself opens in Obsidian like any other.
